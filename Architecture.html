✅ Verify OTP → JWT Issued
POST /auth/verify-otp → redis.get → compare → redis.del → User findOne || create → signTokens() → redis.set('refresh:userId', refreshToken, EX:7d)
Access Token: 15minRefresh Token: 7d in Redis
3
🛍️ Browse Products / Categories
GET /products, GET /categories → Repository → MongoDB query (NO REDIS CACHE currently) → paginated response with .lean()
⚠️ No cache — every request hits DB
4
🛒 Cart Management
POST/PATCH/DELETE /cart → CartService → Cart model (MongoDB). Apply coupon → validate → couponDiscount stored in cart. Guest cart merge on login.
5
💳 Checkout Initiate
POST /orders/initiate → Stock check (Inventory) → calculateCartPricing() [coupon / first-order discount check] → RazorpayService.createOrder(amount, receipt) → {razorpayOrderId, amount, keyId}
First-order discount: SILENT internal
6
💰 Payment (Frontend Razorpay Modal)
Razorpay.js modal opens → User pays via UPI/Card/NetBanking → Razorpay returns {razorpayOrderId, razorpayPaymentId, razorpaySignature} to frontend
7
📋 Order Confirmed — POST /orders/verify
1. HMAC SHA256 signature verify
2. Stock check again
3. Inventory deduct (per item loop) ← NO TRANSACTION!
4. Order create in MongoDB (status: confirmed)
5. CouponUsage.create + Coupon.usageCount++
6. User.orderCount++
7. Cart.clear()
8. WATI.sendOrderConfirmed() [.catch() async fire-forget]
Race Condition Risk: No MongoDB Transaction

POST /auth/admin/login → User.findOne({email}) → role === 'admin' check → bcrypt.compare(password, hash) → signTokens() → redis refresh token store
2
📋 View Orders
GET /admin/orders → authenticate + requireRole('admin') → OrderRepo.findAll(filter) → paginated list with user.name + user.phone populated
3
🚚 Add Tracking (Mark as Shipped)
PATCH /admin/orders/:id/tracking → {trackingId, courier} → OrderRepo.addTracking() → status: 'shipped' + statusHistory.push → User.findById → WATI.sendOrderShipped() [async]

Fix #2 — Redis Product Cache
utils/cache.js [NEW FILE]
const redis = require('../config/redis');

const cache = {
  async get(key) {
    const data = await redis.get(key);
    return data ? JSON.parse(data) : null;
  },
  async set(key, data, ttl = 300) {
    await redis.set(
      key, JSON.stringify(data), 'EX', ttl
    );
  },
  async del(key) { return redis.del(key); },
};

  ); // HMAC verify

  }
