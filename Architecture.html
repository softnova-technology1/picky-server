Admin-Only Order Cancellation Policy:
  • Customers cannot cancel orders after Razorpay payment is confirmed.
  • Only the Store Admin can cancel orders via the Admin Portal (/pickyadmin-softnova2026).
  • When an admin cancels an order, the system automatically runs an atomic $inc query in MongoDB to restore product inventory stocks.

🔌 REST API Endpoints

Core API Surface

Zero hardcoded mocks — All endpoints interact directly with MongoDB Atlas and Redis.

Method Endpoint Description Auth & Role
POST /api/v1/auth/send-otp Dispatches 6-digit OTP via WATI WhatsApp (5m TTL in Redis) Public
POST /api/v1/auth/verify-otp Verifies WhatsApp OTP, generates JWT Access & Refresh tokens Public
POST /api/v1/auth/admin/login Admin email/password login with bcrypt comparison Public
GET /api/v1/products Paginated catalog list with search, category filters, and sorting Public
POST /api/v1/orders/razorpay/create-order Creates Razorpay order with server-calculated dynamic price Customer
POST /api/v1/orders/razorpay/verify Verifies HMAC-SHA256 signature, saves order, deducts stock, sends WATI alert Customer
GET /api/v1/orders/:id/tracking Fetches live 4-stage tracking state, courier name, and AWB Customer
PATCH /api/v1/admin/orders/:id/status Updates status (shipped/AWB/delivered/cancelled + stock restore) Admin Only
POST /api/v1/admin/products Creates new live product with images, variants, and stock Admin Only
GET /api/v1/admin/reports/analytics Calculates gross revenue, order volume, and top-selling products Admin Only
🔐 Security & Credentials

Security & Root Admin Access

Production security model with bcrypt password hashing, JWT stateless access tokens, and HttpOnly cookies.

👑
Root Administrator Credentials

Pre-configured in MongoDB Atlas via seed.js:

  • Portal URL: /pickyadmin-softnova2026
  • Email: admin@picky.com
  • Password: Admin@Picky2026!
  • Role: root_admin
🔒
Payment & OTP Security
  • HMAC-SHA256 signature verification prevents payment tampering.
  • Server re-calculates product prices from MongoDB; zero client price trust.
  • OTPs hashed in Redis with 5-minute auto-expiry and rate-limiting.
  • Atomic MongoDB $inc prevents race conditions in inventory stock.
